Photonspeak MA670V3, MA670-H 192.168.1.1 user / user SC/APC LAN 1-4 GE 1 FXS USB 2x Wi-fi 5 WPA2

  • Вход с правами Администратора логин: Administrator пароль: qazwsx

  • Включение callerID на Photonspeak  -  VOIP/Advance/callerID mode - выставить DTMF
  • После сброса в бридж не отключается DHCP! Снять DHCP с модема. LAN - DHCP - DHCP Mode выставить NONE и нажать Apply Changes.
  • Нет меню отключения (на ночь) ярких светодиодов индикаторной панели
  • Может не поднимать сессию при запуске если модем был выключен некоторое продолжительное время

New Промсвязь AT4 ZXG412D (ПЮРК) 192.168.1.1 user / user SC/APC LAN 1-4 GE 1 FXS 1 USB 2x Wi-fi 5 WPA3
  • Вход в админку user-user (при первом входе предложит сменить, если повторно указать при смене user-user - то их тоже примет)
  • Вход с правами Администратора под логином: SGadmin пароль: Sg-link$
  • MT-PON-AT-4 ПЮРК.465614.006-17, возможно подключение на блоки ZTE и Huawei
  • При первом входе в настройки модема требуется обязательная смена стандартного пароля. Интерфейс модема схож с TS4224 но более урезанный.
  • В отверстии RST расположена кнопка сброса к заводским настройкам (боковая панель). Для сброса следует удерживать кнопку не менее 10 секунд
  • Включение Wifi - однократное нажатие кнопки WLAN (боковая панель). Название стандартной сети и пароль указаны на наклейке(GPON-2.4G-XXXXXX, GPON-5G-XXXXXX).
  • Настройка WLAN отличается от всех модемов. WLAN - Security - Encryption - Выбрать тип шифрования WPA 2 Mixed либо WPA3. После выбора типа шифрования появится поле Pre-Shared-Key для ввода нового пароля и дополнительные параметры настройки Wi-fi.
  • Зеленый PON разъем для подключения оптоволоконного кабеля расположен снизу на донышке модема, при выдаче абоненту в нем стоит черная пластиковая заглушка
  • Серийный номер для блока ZTE отображается в формате HWTCXXXXXXXX, для HUAWEI в обычном 4857XXXXXXXXXX (появились с серийным 5347544XXXXXXXXX)
Недостатки и возможные проблемы:
  • Проблемы с неработающей IPTV ZALA на С300 v.1.2.5 пробовать перерегистрировать. После перерегистрации проверять меняется ли VLAN 20 на 1000 для IPTV.
  • Нет возможности настроить DHCP и Port-Mapping под учеткой user
  • Слабо защищенная wi-fi сеть, достаточно подставить 8с к названию wi-fi сети чтобы получить пароль
  • Неочевидная смена пароля от wi-fi - нужно выбрать шифрование, только тогда появляются поля для настройки
  • На OLT ZTE некорректно отображается оптический параметр TX(up), у рабочих аб-тов должен показывать ~2-3 dBm, а показывает ~ -27-28
  • Партия с серийным 5347544XXXXXXXXX - настройка вай-фай не соответствует наклейке на корпусе
