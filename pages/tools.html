Расшифровка сокращений:
  • AV - (antivirus) - фильтрация трафика от вредоносного программного обеспечения;
  • Anti-DDoS - защита от различных типов распределённых атак (DDoS-атак);
  • DNS - доступ к информации, размещенной в сети Интернет, осуществляется с использованием специализированной системы DNS серверов;
  • IPS - (intrusion prevention system) - обнаружение уязвимостей систем защиты информации;
  • FW - (firewall) – межсетевое экранирование по портам протоколов транспортного уровня;
  • FW 1 - Доступ в Интернет + электронная почта;
  • FW 2 - Доступ в Интернет + электронная почта + Мгновенные сообщения (Месседжеры);
  • FW 3 - Доступ в Интернет + электронная почта + Мгновенные сообщения (Месседжеры) + FTP;
  • БелГИЭ - (web filtering) - web-фильтрация, ограничение доступа к информации с использованием списков, формируемых РУП «БелГИЭ»;
  • Фильтр оператора - (web filtering) - web-фильтрация, ограничение доступа к информации с использованием списка РУП «Белтелеком»;

Domain

Проверка DNS-записей доменов и IP-адресов

Типы ресурсных записей DNS
Тип Назначение
A Связывает доменное имя с IPv4-адресом сервера. Указывает, где физически расположен сайт
AAAA Связывает доменное имя с IPv6-адресом сервера. Аналог A-записи для нового формата адресов
CNAME Создает псевдоним для доменного имени. Указывает, что один адрес должен вести на тот же IP, что и другой. Часто используется для поддоменов
MX Определяет серверы входящей почты и приоритет каждого из них
TXT Содержит произвольную текстовую информацию. Применяется для проверок безопасности почты (SPF, DKIM), подтверждения прав на домен и других целей
NS Указывает авторитативные DNS-серверы для домена. Именно эти серверы хранят и предоставляют информацию об остальных ресурсных записях зоны
SOA Начальная запись зоны. Содержит служебную информацию о домене: первичный DNS-сервер, контакт администратора и тайминги обновления и кэширования
SPF Cодержит информацию о списке серверов, которые имеют право отправлять письма от имени заданного домена. Позволяет избежать несанкционированного использования.
PTR Обратная запись, связывающая IP-адрес с доменным именем. Используется для обратного DNS-поиска, в том числе для проверок при отправке почты
TLSA TLSA-запись позволяет владельцу домена подтвердить подлинность используемого сертификата или цифровой подписи средствами DNSSEC. С помощью TLSA-записи вы можете сохранить отпечаток TLS или SSL-сертификата на вашем DNS-сервере.

Open ports

Проверка открытых портов на доступность

Список популярных портов
  • 20 & 21 - FTP (File Transfer Protocol)
  • 22 - SSH (Secure Shell)
  • 23 - Telnet, a Remote Login Service
  • 25 - SMTP (Simple Mail Transfer Protocol)
  • 53 - DNS (Domain Name System)
  • 80 - HTTP (Hypertext Transfer Protocol)
  • 110 - POP3 (Post Office Protocol 3)
  • 115 - SFTP (Secure File Transfer Protocol)
  • 123 - NTP (Network Time Protocol)
  • 143 - IMAP (Internet Message Access Protocol)
  • 161 - SNMP (Simple Network Management Protocol)
  • 194 - IRC (Internet Relay Chat)
  • 443 - SSL / HTTPS (Hypertext Transfer Protocol Secure)
  • 445 - SMB
  • 465 - SMTPS (Simple Mail Transfer Protocol over SSL)
  • 554 - RTSP (Real Time Stream Control Protocol)
  • 873 - RSYNC (RSYNC File Transfer Services)
  • 993 - IMAPS (Internet Message Access Protocol over SSL)
  • 995 - POP3S (Post Office Protocol 3 over SSL)
  • 3389 - RDP (Remote Desktop Protocol)
  • 5900 - VNC
  • 8080 - HTTP-Proxy
